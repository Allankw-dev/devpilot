# Getting help

- **Setting it up?** Start with [`docs/SELF_HOSTING.md`](docs/SELF_HOSTING.md). Each integration has its own guide:
  [Auth](docs/AUTH.md), [GitHub](docs/GITHUB.md), [AI](docs/AI.md).
- **Something broke?** Check the troubleshooting tables in those guides, then open a
  [bug report](https://github.com/Allankw-dev/devpilot/issues/new?template=bug_report.yml).
  Remove API keys, tokens and private code from anything you paste.
- **Have an idea?** Open a
  [feature request](https://github.com/Allankw-dev/devpilot/issues/new?template=feature_request.yml).
- **Found a security problem?** Do not open an issue. See [`SECURITY.md`](SECURITY.md).

DevPilot is maintained by one person in their spare time, so replies are not instant and there is no
guaranteed support level.
